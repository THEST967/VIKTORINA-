# VIKTORINA
# 🎮 Viktorina — простая викторина для ПК на языке програмированния python

**Viktorina** — это начальный проект викторины, где игроку предлагается отвечать на вопросы из разных категорий. Игра работает на ПК и запускается в консольном режиме.

## 📋 Возможности
- 🧠 Вопросы с несколькими вариантами ответа
- 🎲 Случайный выбор вопросов
- 📜 Простой текстовый интерфейс

⚠️ Счётчик очков **пока не реализован**, но планируется в будущих версиях.

## 🚧 Статус проекта
🔧 Активная разработка. Сейчас работает базовая логика игры:
- Загрузка вопросов
- Проверка правильного ответа
